<objective>
Standardize retries across connector families using an async-native retry library (stamina) and a shared retry/backoff policy so that transient failures (rate limits, brief upstream outages, handshake failures) behave consistently and predictably.

Purpose: REL-01 requires removing per-connector bespoke retry loops and making backoff semantics observable and uniform. Today, retry behavior diverges across connector families:
- `src/connectors/gemini_base/streaming_executor.py` implements its own cooldown + retry waits and parses retry hints in multiple formats.
- `src/connectors/openai_codex/executor.py` implements bespoke auth-refresh retry delays with direct `await asyncio.sleep(delay)` calls.
- Core also duplicates retry-after extraction logic (`src/core/services/failure_handling_strategy.py`) separate from resilience handlers.

Output: A single stamina-backed async retry abstraction (`AsyncRetryExecutor`) + a canonical retry-after extractor, with the first migrations applied to the two largest retry hotspots (Gemini Code Assist streaming + Codex auth refresh).
</objective>
