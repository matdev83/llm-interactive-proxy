<objective>
Implement a circuit breaker that automatically excludes unstable backends from routing decisions, and integrate endpoint health gating so that unhealthy endpoints stop receiving traffic until they recover.

Purpose: REL-02 requires the proxy to stop repeatedly routing traffic to failing backends. The codebase already has:
- Rate-limit cooldown state (`RateLimitStateManager`) and resilience availability checks (`ResilienceCoordinator.check_availability`)
- A health check subsystem with endpoint registry + state transitions (`EndpointRegistry`, `HealthStateManager`) but no routing gate wired to those states

Output: Circuit breaker state manager + error handler + coordinator gating that (a) opens after configurable failure thresholds, (b) half-opens with bounded probing, and (c) rejects unhealthy endpoints based on `EndpointRegistry` health state.
</objective>
